# Threat Modeling Guides
Free guides, best practices and research on threat modeling and security by design, from Security Compass.
## Guides
- [**Best Practices for Optimizing a Threat Modeling Program in 2027**](https://www.securitycompass.com/whitepapers/threat-modeling-program-best-practices-2027/?utm_source=github&utm_content=program-best-practices): six practices for keeping a program in step with AI-assisted development, including continuous modeling, framework standardization (STRIDE, LINDDUN, MAESTRO) and metrics. Includes Gartner-sourced RACI tables and a pitfalls checklist.
- [**Threat Modeling That Keeps Up With Your SDLC**](https://www.securitycompass.com/whitepapers/threat-modeling-sdlc/?utm_source=github&utm_content=sdlc): how your developers' AI coding agent can build and maintain the threat model in the same conversation that writes the code.
- [**Threat Modeling for Agentic AI**](https://www.securitycompass.com/whitepapers/threat-modeling-for-agentic-ai/?utm_source=github&utm_content=agentic-ai): what changes when your systems include AI agents that call tools, read data and take action, and what a complete model looks like.
